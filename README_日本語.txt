JLPT N4 漢字カード ネパール版（PWA試作）

内容
- 300語のネパール版データ
- 表：日本語の漢字語彙のみ
- 裏：漢字語彙、ひらがな読み、英語、ネパール語
- 覚えた／未習得の記録（端末内 localStorage）
- ランダム表示、未習得語の復習
- Service Worker によるオフラインキャッシュ

使い始める方法
1. ZIPを展開します。
2. HTTPS対応の静的ホスティング（例：GitHub Pages等）にフォルダ内のファイルをアップロードします。
3. 公開URLをスマートフォンのブラウザでオンライン時に開き、読み込み完了まで待ちます。
4. AndroidはChromeのメニューから「ホーム画面に追加」または「アプリをインストール」。
   iPhoneはSafariの共有メニューから「ホーム画面に追加」。
5. 一度読み込んだ後、機内モード等でオフライン動作を確認します。

注意
- PWAは file:// で直接開くのではなく、HTTPSのWebサイトとして公開する必要があります。
- このZIP自体はWeb上に公開されていません。公開作業は別途必要です。
- 学習記録はその端末・そのブラウザ内に保存され、別端末とは同期しません。
- 翻訳は配布前にネパール語母語話者による校正を推奨します。
- 語彙はJLPT公式の固定語彙リストではなく、N4対策用の候補300語です。
